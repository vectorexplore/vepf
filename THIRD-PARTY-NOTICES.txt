3. Dynamically Linked Linux System Libraries
--------------------------------------------------------------------------------
The VePF native runtime (libmilcorez.so) dynamically links at runtime against
standard system libraries installed on the host Linux distribution via
install-deps.sh. These libraries are not statically bundled inside VePF and
remain licensed under their respective upstream open-source licenses:

  * libvips (Image Processing Library)
    Website: https://www.libvips.org
    License: GNU Lesser General Public License v2.1 or later (LGPL-2.1-or-later)

  * GStreamer & gst-plugins-base (Multimedia Framework)
    Website: https://gstreamer.freedesktop.org
    License: GNU Lesser General Public License v2.1 or later (LGPL-2.1-or-later)

  * ImageMagick (vips-magick format delegate for .ico / .bmp decoding)
    Website: https://imagemagick.org
    License: ImageMagick License (Apache-2.0 compatible)

  * FreeType (Font Rendering Library)
    Website: https://freetype.org
    License: FreeType License (FTL) / GNU General Public License v2.0 or later

  * OpenSSL (Cryptography and SSL/TLS Toolkit)
    Website: https://www.openssl.org
    License: Apache License 2.0 (Apache-2.0)

  * giflib (GIF Image Decoding Library)
    Website: https://giflib.sourceforge.net
    License: MIT License

  * Vulkan Loader (libvulkan) & Mesa 3D / Lavapipe (llvmpipe)
    Website: https://www.khronos.org/vulkan / https://www.mesa3d.org
    License: Apache-2.0 / MIT License

  * libxkbcommon, libX11, and Wayland Client Libraries
    Website: https://xkbcommon.org / https://wayland.freedesktop.org
    License: MIT License
